# AGENTS.md — SOD1 FEP variant pipeline

> **This file is a pointer, not a rulebook. Read [`CLAUDE.md`](CLAUDE.md).**

Until 2026-09-12 this file was a fork of `CLAUDE.md` that had stopped being updated. An agent
routed here received the **pre-audit** rulebook: it predated the pre-registered gate thresholds,
the per-leg protocol hashes, the lambda-aware minimisation requirement, the first-light traps,
the GPU-reschedule contract, and the 2026-09-12 reference-state audit. Every one of those is a
rule whose violation has already cost this project either GPU hours or a wrong number.

Two divergent rulebooks is the failure mode itself, so this one is not being re-synced — it is
being retired. **`CLAUDE.md` is the single operating document for every agent, regardless of
which tool you are.**
